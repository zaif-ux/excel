Embassy Outreach – Leadership Dashboard (Excel)

An Excel dashboard and data-quality review for tracking embassy outreach: pipeline status, regional engagement, overdue follow-ups and owner workload.

What's inside
File	Description
Embassy_Outreach_Dashboard.xlsx	Dashboard, Data Quality Review, sample data and label-mapping sheets
embassy_outreach_sample_data.csv	The raw sample data (17 columns, 78 records)
Dashboard
KPI tiles: unique embassies, outreach coverage, engagement rate, active partnerships, overdue follow-ups, stale contacts, records with data issues
Pipeline by status, regional funnel, engagement mix, last-contact trend by month
Owner workload and a top-10 overdue follow-up list
Auto-generated insight lines
Data Quality Review

21 checks with live counts and severity ratings, including duplicates, text-formatted dates, impossible date order, inconsistent labels, missing owners/emails/phones and status-versus-activity conflicts.

Skills shown

Excel formulas (COUNTIFS, SUMIFS, SUMPRODUCT, INDEX/MATCH), data cleaning with lookup tables, conditional formatting, charts and dashboard design.

Data note

The data is synthetic: 78 sample records generated for this project, with data-quality problems added on purpose. All findings are illustrative, not real. The workbook was built with AI assistance (Claude).

Using your own data

Paste your data into Outreach_Data columns A–Q (same headers). The calculated columns and dashboard update automatically; extend the formulas if you add rows.
